# Netflix_Performance_Insights_Dashboard

## Project Overview
An interactive Microsoft Excel dashboard designed to analyze Netflix-related stock performance, review activity, customer sentiment, and content-related metrics.

## Dashboard Highlights
- KPI cards for trading days, stock volume, daily returns, total reviews, titles released, and average IMDb score.
- Stock return distribution analysis.
- Customer sentiment distribution and review activity.
- Reviews versus stock performance comparison.
- Netflix stock price trend visualization.
- Interactive slicers for filtering data by date, trading status, sentiment, and other available fields.

## Tools & Technologies
- Microsoft Excel
- PivotTables and PivotCharts
- Data cleaning and analysis
- KPI cards and interactive slicers
- Data visualization
